# 我的出片参考图

把想参考的出片图片直接复制到对应景点文件夹里，app 会自动显示在对应景点的画廊末尾。

## 使用方法

1. 从小红书/微信/浏览器保存或截图你想参考的照片
2. 复制到下面对应的文件夹里（支持 jpg / png / webp / heic）
3. 文件名会显示为图片说明（建议用有意义的命名，如 `蓝调时刻-门框构图.jpg`）
4. 保存后 Vite 热更新会自动刷新，无需改代码

## 提示

- 图片会打包进 app，离线也能看（所以别放太多太大的图）
- 建议每张控制在 500KB 以内，手机截图通常没问题
- 如果需要新增景点文件夹，在 `src/utils/userPhotos.ts` 的 `folderToSpotKey` 里加一行映射即可
